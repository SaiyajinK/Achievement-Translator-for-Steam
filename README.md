<p align="center">
  A simple Millennium plugin that adds button to translate achievement names and descriptions into the Steam client's language.<br>
  Most game achievements are already translated into your language. However, some games, especially smaller indie titles (but not exclusively), don't include translations for the player's language. This plugin solves that problem.
</p>

</p>
  <img width="700" height="1" src="https://via.placeholder.com/700x1/262626/262626">
</p>

### ✨ Features :

| Feature | Description |
|---|---|
| 🌐 **Achievement Translation** | Translates achievement names and descriptions in one click |
| 🌍 **30 Languages** | Automatically translates into the Steam client's language |
| 🎮 **In-Game Overlay** | Works in both the Steam Library and the in-game overlay |
| 🔄 **Original Text Toggle** | Instantly switch between translated and original text |
| 💾 **Persistent Cache** | Saves translations locally for instant reuse, even after restarting Steam |
| 🎯 **Smart Translation** | Translates only the achievements in the selected tab |
| ⏳ **Progress Tracking** | Displays translation progress in real time |
| 🪶 **Lightweight** | No modifications to game files |
| 🚀 **Easy Setup** | Simple installation through Millennium |

### ✅ Manual Installation :

| Step | Action |
|--------|--------|
| 1️⃣ | Download the latest release [here](https://github.com/SaiyajinK/Achievement-Translator-for-Steam/releases) |
| 2️⃣ | Navigate to `C:\Program Files (x86)\Steam\millennium\plugins\` |
| 3️⃣ | Extract and copy the `com.saiyajink.achievementtranslator.star` file into the `plugins` directory |
| 4️⃣ | Restart Steam |
| 5️⃣ | Enable the plugin from the Millennium settings |
